# Reality Compiler

Speculative `reality-compiler` experience built on the shared `api-server` + `mockup-sandbox` stack—exploratory UI around “compiling” narratives or systems.

## 💼 Real-World Use Case
Creative tooling and systems thinkers experimenting with metaphorical compilers; best framed as **R&D** unless mapped to a concrete buyer like education or simulation.

## 💰 Potential Value
- Low standalone commercial clarity; strongest as part of a broader portfolio showing rapid UI iteration on a common backend.
- Could inspire domain-specific “compiler” tooling (lesson plans, configs) with repositioning.

## 🚀 Demo / Access
Self-hosted / local only. Standard pnpm workspace + database setup. No production link in metadata.
